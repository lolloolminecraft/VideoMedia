# VideoMedia

This is for Amira.

**VideoMedia 1.0** — плагин для Lampa с собственным удобным интерфейсом: мягкие цвета, боковое меню, две темы и отдельные экраны для каталога, списка «Запланировано» и просмотра.

## Установка в Lampa

Скопируйте ссылку в **Настройки → Расширения → Добавить плагин**:

```text
https://raw.githubusercontent.com/lolloolminecraft/VideoMedia/main/lampa/videomedia.js
```

Перезапустите Lampa. В левом меню появится **VideoMedia**.

## Экраны

- **Главная:** спокойный приветственный блок и три ближайших запланированных названия.
- **Каталог:** поиск через клавиатуру Lampa, категории «Фильмы», «Сериалы», «Мультфильмы», «Аниме», карточки с кнопками «Смотреть» и «＋».
- **Запланировано:** сохраняемый на устройстве список с кнопками просмотра и удаления.
- **Просмотр:** отдельный экран с выбором установленного источника/балансера, доступом к настройкам озвучки, очередью следующих фильмов либо списком серий, если источник метаданных предоставляет сезоны.
- **Оформление:** переключатель тёмной (графит + сиреневый) и светлой (светлая слоновая кость + сиреневый) тем.

Приветственный блок размещён только на главной странице.

## Интеграция с источниками

VideoMedia не содержит фильмов, прямых ссылок на видео или собственных балансеров. Каталог использует интерфейс источника TMDB, встроенный в Lampa. Кнопка «Воспроизвести» передаёт карточку Lampa или одному из обнаруженных компонентов установленных плагинов. По умолчанию **«Все источники Lampa»** открывает стандартную карточку фильма с доступными установленными плагинами: этот путь рекомендуется, если у конкретного плагина нестандартное название компонента.

Звуковые дорожки, озвучки, субтитры, качество, перемотка и реальное воспроизведение управляются выбранным онлайн-плагином и плеером Lampa. VideoMedia не может заранее перечислить дорожки незапущенного стороннего видео. Выбор конкретной серии из своего списка передаёт сезон и номер эпизода поставщику, если он умеет принимать эти параметры; иначе серию нужно выбрать в интерфейсе самого источника.

Поддержка всех сторонних источников без исключения не гарантируется, так как их интерфейсы различаются. Плагин не меняет их код и не подменяет стандартный проигрыватель Lampa.

## Проверка

```bash
node --check lampa/videomedia.js
node lampa/test.js
```

## Предыдущий дизайн

Исходный сайт оставлен в `dist/` только как сохранённый визуальный образец для развития плагина. Для работы VideoMedia в Lampa он не нужен: используется один файл `lampa/videomedia.js`.
