# VideoMedia

This is for Amira.

Уютный адаптивный сайт для поиска фильмов, мультфильмов, аниме и сериалов, планирования и просмотра видео с разрешёнными источниками.

## Возможности

- Список «Запланировано», отметка просмотренного и управление очередью.
- Сохранение просмотра на устройстве, возобновление с нужного момента.
- Плеер MP4 с перемоткой, громкостью, скоростью, полноэкранным режимом и PiP; официальные видео других фильмов со встроенным YouTube-плеером.
- Выбор серии для демонстрационного мультсериала Caminandes через официальные ролики Blender.
- Поиск названий из открытых API Apple iTunes и TVMaze, с возможностью добавления в список.
- Мягкая тёмная тема, адаптивная версия для телефона, клавиатурные сокращения.

## Запуск

Откройте `dist/index.html` в браузере или запустите любой статический HTTP-сервер в каталоге `dist`. Для поиска нужен интернет; списки и прогресс хранятся в `localStorage` браузера.

## Видео и права

Сайт не предоставляет доступ к платным фильмам без разрешения. Встроенные полные фильмы — открытые проекты Blender Foundation, используемые для демонстрации просмотра. Сериал Caminandes встроен с видеоплатформы правообладателя. Видео Elephants Dream поступает из VPRO Open Beelden по CC BY 3.0. Поиск по каталогам iTunes и TVMaze не гарантирует доступность полного видео. Функция выбора озвучки зависит от фактически предоставленных аудиодорожек; в первой версии одна оригинальная дорожка у MP4 и настройки внешнего плеера у встроенных роликов.

Для полноценного постоянно обновляемого каталога можно подключить TMDB API с серверным хранением токена и соблюдением требований атрибуции, а для совместного сохранения списков — пользовательские аккаунты и базу данных. Эти интеграции пока не включены.
